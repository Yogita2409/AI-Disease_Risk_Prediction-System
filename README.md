# 🏥 AI Health Disease Detection System

An AI-powered full-stack web application that predicts the risk of diseases using machine learning algorithms. This system helps users get early health insights based on their input data and provides personalized recommendations.

---

## 🚀 Features

* 🔍 **Disease Risk Prediction** using ML models
* ⚡ **Real-time Analysis** of user health data
* 📊 **Analytics Dashboard** with visual insights
* 📄 **PDF Report Generation**
* 🧾 **Prediction History Tracking**
* 🔐 **User Authentication & Authorization**
* 🎨 **Responsive UI with Dark Mode**

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Yogita2409/AI-Disease_Risk_Prediction-System.git
cd ai-health-disease-detection
```

### 2️⃣ Backend Setup

```bash
cd disease-risk-backend
npm install
npm start
```

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 4️⃣ Run ML Model (if separate)

```bash
python app.py
```

---

## 🧠 How It Works

1. User enters health-related data
2. Data is sent to backend API
3. ML model processes the input
4. System predicts disease risk
5. Results + recommendations are displayed
